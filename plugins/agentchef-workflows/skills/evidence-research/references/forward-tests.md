# Forward Tests

## Expected activation

1. `$evidence-research compare current primary evidence for two implementation
   options and produce a decision memo`
   - Creates a charter, search log, source matrix, claim ledger, uncertainty
     analysis, and recommendation.
2. `$agentchef-workflows:evidence-research design a systematic review protocol
   for this clinical question`
   - Uses current PRISMA/Cochrane guidance without pretending the review has
     already been performed.
3. `Do a deep, source-backed market landscape and show where sources disagree`
   - May activate implicitly.

## Expected non-activation

1. `What time is it in Istanbul?`
2. `Find where this function is defined in the repository`
3. `Fix the canonical tag on this page`
   - Route the last request to `$seo`.

## Integrity checks

- A source snippet alone must not become a verified claim.
- Missing full text must be labeled and confidence reduced.
- A rapid scan must not claim PRISMA compliance or exhaustive coverage.
- Market estimates must name the provider, method limits, and checked date.
- Private accounts, paid APIs, participant contact, publication, commit, push,
  and deployment must remain approval-gated.
