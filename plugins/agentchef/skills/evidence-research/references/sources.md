# Method Source Ledger

Checked on 2026-07-29. Refresh API and handbook details before use.

## Review and quality methods

- [PRISMA 2020](https://www.prisma-statement.org/prisma-2020)
  - Reporting guidance and checklists for systematic reviews.
- [Cochrane Handbook for Systematic Reviews of Interventions](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current)
  and [Chapter 4: Searching for and selecting studies](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-04)
  - Current systematic-review methods and search guidance.
- [NIST/SEMATECH e-Handbook: Exploratory Data Analysis](https://www.nist.gov/publications/nistsematech-e-handbook-statistical-methods-chapter-1-exploratory-data-analysis)
  - Exploratory analysis before formal modeling.
- [The Aqua Book](https://www.gov.uk/guidance/the-aqua-book)
  - UK government guidance on quality assurance for analysis.
- [FAIR Guiding Principles](https://doi.org/10.1038/sdata.2016.18)
  - Findability, accessibility, interoperability, and reuse for research
    artifacts, subject to lawful access conditions.

## Discovery APIs

- [Crossref REST API access and authentication](https://www.crossref.org/documentation/retrieve-metadata/rest-api/access-and-authentication/)
  - Public metadata access; identify polite requests, cache results, and use
    backoff. No credential belongs in a skill or report.
- [OpenAlex API introduction](https://developers.openalex.org/api-reference/introduction)
  - Scholarly graph discovery. An API key is required under the current 2026
    policy; keep it outside prompts, source, reports, and logs.
- [NCBI E-utilities quick start](https://www.ncbi.nlm.nih.gov/sites/books/NBK25497/)
  - PubMed and NCBI programmatic retrieval. Observe current request-rate and
    API-key guidance.
