# Research Charter

- Decision supported: Define the concrete decision this research will inform.
- Primary question: State one answerable question.
- Sub-questions: List the smallest useful set.
- Audience: Identify who will use the result and at what technical depth.
- Scope: State subject, geography, population, period, and source languages.
- Exclusions: State what will not be evaluated.
- Evidence standard: Name preferred primary and secondary source classes.
- Method: Choose rapid scan, structured review, systematic review, landscape,
  implementation study, qualitative, quantitative, or mixed methods.
- Deliverables: Name the memo, report, slides, source matrix, data, or code
  package required.
- Deadline and stopping rule: State the real constraint and when collection is
  sufficient.
- Approval gates: List private data, paid access, participants, external
  contact, publication, or account access that requires authorization.
